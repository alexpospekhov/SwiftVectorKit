# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

SwiftVectorKit executes code analysis 100% locally on your machine and never transmits repository code or AST chunks to remote servers without explicit user invocation.

If you discover a security vulnerability within SwiftVectorKit:
1. Please do not report security issues through public GitHub issue tracking.
2. Submit a confidential advisory report via GitHub's **Security Advisories** tab on this repository.
3. The maintainers will acknowledge receipt within 48 hours and coordinate disclosure.
